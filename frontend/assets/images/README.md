# App images

Place **basarat_logo.jpg** here (your Basarat logo).

- Used as the **app launcher icon** (phone home screen).
- Used as the **small logo** in the app bar (top left, next to "بصارت").

Recommended: square image, at least 1024×1024 for the launcher icon. The in-app logo is shown at 28×28.

After adding the file, run:
```bash
dart run flutter_launcher_icons
```
to update the Android/iOS app icon.
